# GitHub Universe 3D

Visualização 3D interativa que transforma um perfil do GitHub em um universo:
galáxia = perfil, planeta = repositório, luas = linguagens, textura do planeta =
grid de contribuições, sol = globo interativo e Octocat piloto como guia.

> Status: protótipo e planejamento. A implementação (Next.js + React Three Fiber) ainda não começou.

## Conteúdo

- [`docs/brief.md`](docs/brief.md): brief completo do projeto (escopo, stack, perguntas em aberto).
- [`demo/index.html`](demo/index.html): demo em Three.js com dados de exemplo. Abra no navegador.
- [`design/`](design): artboards do Octocat piloto, da nave retrô e do gorro-Clawd (formato `.dc.html` do Claude Design).

## Stack planejada

Next.js, TypeScript, React Three Fiber, Zustand, Tailwind, GitHub GraphQL API, Vercel.

## Aviso

Octocat é marca do GitHub e o Clawd é do Claude Code (Anthropic). Este é um projeto de portfólio sem fins comerciais e não é afiliado a nenhuma das duas empresas.
